C++ Language API Reference

In the C++ API there are a few classes that the user sees where most of the interaction occurs. The index class implements most of the dataman verbs. Unlike the C API, C++ doesn't try to use defines to make the API more EDITOR-like. The differences in the general syntax and feel of C++ makes that sort of thing out of place.
For all user routines, all that needs to be included is either the <dataman/dataman.hh> or the <dataman/sort.hh> include files. All programs need to be linked with the -ldataman++ library switch.
