iclose



Summary

#include <dataman/dataman.h>

iclose(idx_name);

short int mode;
char *idx_name;

Description

This routine closes an open index. The argument idx_name is the name of the index to close. Since you may have only six indexes open at any one time, it may be necessary to close an index at other times besides the end of your program. The server keeps track of the indexes you open during a connection, so if that connection is dropped, it attempts to close it in the server.

Example

    #include <dataman/dataman.h>

    char ix1[] = "name_ix";         /* global index name */

    main(int argc, char *argv[])
    {

        init_dataman(argc,argv);    /* init process */
        iopen(ix1,UPDATE);          /* open the index */
          ...                       /* process */
        iclose(ix1);
    }
