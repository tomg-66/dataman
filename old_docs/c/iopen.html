iopen



Summary

#include <dataman/dataman.h>

iopen(idx_name,mode);

short int mode;
char *idx_name;

Description

This routine opens an index file for processing. The argument idx_name is the name of the index to open, and mode is either of the manifest constants RDONLY, or UPDATE for read only, or read/write respectively. The user may have only six indices open at any given time.

Example

    #include <dataman/dataman.h>

    char ix1[] = "name_ix";         /* global index name */

    main(int argc,char *argv[])
    {

        init_dataman(argc,argv);    /* init process */
        iopen(ix1,UPDATE);          /* open the index */
          ...                       /* process */
    }
