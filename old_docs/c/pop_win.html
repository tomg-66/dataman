pop_win



Summary

#include <dataman/dataman.h>
      -or-
#include <dataman/sort.h>

pop_win();

Description

pop_win restores the area of the screen defined by the last call to new_win(). The windows created by new_win and destroyed by pop_win are done in a stack like manner. All prior information located under the screen area freed by pop_win is set to the stat it was in when new_win was called.

Example

    #include <dataman/dataman.h>

    main(int argc, char *argv[])
    {
          ....
        new_win(5,10,10,40,CYAN,GROW);
          ...
        pop_win();
    }
