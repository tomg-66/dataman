window



Summary

#include <dataman/dataman.h>
      -or-
#include <dataman/sort.h>

window(row1,col1,row2,col2,attrib) else ...

int row1, col1;
int row2, col2;
int attrib;


Description

window paints a box and clears the center of it using the background color attrib. Row1 and col1 is the row and column number of the upper left hand corner, and row2, col2 is the lower right hand corner. The mode is one of the color constants BLACK, BLUE, GREEN, CYAN, RED, MAGEN, BROWN, and L_GREY.

Example

    #include <dataman/dataman.h>

    main(int argc, char *argv[])
    {
          ....
        window(5,10,10,40,MAGEN);
          ...
    }
This will paint a box with a magenta center 6 lines by 31 columns begining at point (5,10) on the screen.
